# 外卖配送平台技术方案

保存时间：2026-09-23

建议先做“模块化单体后端 + Vue 3 前端”，不要一开始上微服务。先完成用户、商家、商品、购物车、订单、骑手配送等核心流程，后期再拆分服务。

## 1. 推荐技术栈

| 部分 | 推荐技术 |
|---|---|
| 后端语言 | Java 21，最低 Java 17 |
| 后端框架 | Spring Boot 3.x |
| 构建工具 | Maven |
| 数据库 | MySQL 8.x |
| 缓存 | Redis 7.x |
| ORM | MyBatis-Plus |
| 认证授权 | Spring Security + JWT |
| 接口文档 | SpringDoc OpenAPI / Knife4j |
| 实时通信 | WebSocket |
| 对象存储 | MinIO 或阿里云 OSS |
| 前端框架 | Vue 3 + TypeScript |
| 前端构建 | Vite |
| UI 组件 | Element Plus |
| 状态管理 | Pinia |
| 路由 | Vue Router |
| HTTP 请求 | Axios |
| 图表 | ECharts |
| 地图配送 | 高德地图 |
| 部署 | Docker Compose + Nginx |

## 4. 前端项目依赖

使用 Vue 3 + TypeScript + Vite：

~~~bash
npm create vite@latest frontend -- --template vue-ts
cd frontend

npm install
npm install vue-router pinia axios
npm install element-plus @element-plus/icons-vue
npm install echarts
npm install @amap/amap-jsapi-loader

npm install -D sass
npm install -D unplugin-auto-import unplugin-vue-components
~~~

前端目录建议：

~~~text
frontend/src/
├── api/                     接口请求
├── assets/                  图片和样式
├── components/              通用组件
├── layouts/                 页面布局
├── router/                  路由
├── stores/                  Pinia 状态
├── types/                   TypeScript 类型

├── views/

│   ├── order/               订单
│   ├── delivery/            骑手和配送

└── App.vue
~~~

## 5. 第一阶段需要实现的功能

1. 用户注册、登录、JWT Token。
2. 商家创建、营业状态、分类和商品管理。
3. 用户浏览商家和商品。
4. 购物车、规格、数量和备注。
5. 创建订单、订单价格计算。
6. 模拟支付。
7. 商家接单、出餐和取消。
8. 骑手接单、取餐、送达。
9. 订单状态跟踪和 WebSocket 推送。
10. 用户地址、评价和订单记录。

第一阶段建议先把支付做成模拟支付，等整个下单流程稳定后再接微信支付。

## 6. 后续实施顺序

1. 创建 backend 和 frontend 基础工程。
2. 设计数据库表：用户、地址、商家、分类、商品、规格、购物车、订单、订单项、骑手、配送记录、优惠券、评价。
3. 完成统一响应、全局异常处理、接口日志和参数校验。
4. 完成 JWT 登录和基于角色的权限控制。
5. 按模块开发 REST API，并生成 OpenAPI 文档。
6. 完成用户端、商家端和骑手端页面。
7. 接入 WebSocket 推送订单状态。
8. 使用 Docker Compose 启动 MySQL、Redis、MinIO 和应用。
